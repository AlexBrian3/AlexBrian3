## Featured projects

**Solana infrastructure**
* `smart-transaction-stack`: an AI assisted Solana transaction stack built around Jito bundles and Yellowstone streaming. It focuses on practical transaction intelligence and low latency execution, not just a pretty UI.
* `Nexus-Pay`: an offline first Solana payment relay. It uses a state channel design so payments keep working even when connectivity is poor.

**Privacy and compliance**
* `anon-compliance`: private compliance proofs on Stellar testnet using a Groth16 verification flow. A good fit for ZK, compliance and regulated crypto use cases.

**Agent infrastructure**
* `agent-vault`: a live, frontend facing vault for agent custody and control, built to test the idea of agent ownership in public.
* `quantedge`: an autonomous on chain benchmarking and quant trading agent for the Mantle ecosystem, with market intelligence and smart contract driven execution experiments.

**Product surfaces**
* `edge-arena`, `alpha-desk`, `snowball-studio`: live web products that make the underlying systems easy for real users to understand.
